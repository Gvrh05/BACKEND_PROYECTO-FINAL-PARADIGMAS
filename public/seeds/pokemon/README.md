# Pokémon · Desafío de la Pokédex

Datos obtenidos de PokéAPI el 18 de noviembre de 2026. `catalog.json` conserva las URLs de origen y de las ilustraciones `official-artwork` de cada Pokémon. Se incluyen las imágenes para que el cuestionario predeterminado y las partidas funcionen sin consultar la API durante el juego.

Las preguntas usan las formas estándar y las estadísticas base, sin naturaleza, entrenamiento, habilidades, evoluciones mega ni formas regionales. PokéAPI expresa el peso en hectogramos y la altura en decímetros. Las comparaciones de peso usan las mismas unidades.

Pokémon y sus personajes pertenecen a sus respectivos titulares. PokéAPI es un proyecto independiente. Fuente y documentación: https://pokeapi.co/docs/v2
