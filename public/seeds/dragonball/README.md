# Dragon Ball · Desafío de los Guerreros Z

Fichas e imágenes obtenidas de https://dragonball-api.com/api/characters/ el 18 de noviembre de 2026. `catalog.json` conserva la URL de cada ficha y su imagen original. Las ilustraciones se guardan en PNG para usar el mismo almacenamiento y flujo de partida del proyecto.

El cuestionario usa biografías, relaciones familiares, afiliaciones y transformaciones. Se evitan preguntas sobre niveles de ki ambiguos entre sagas. Las ilustraciones y los personajes pertenecen a sus respectivos titulares.
